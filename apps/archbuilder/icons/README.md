# ArchBuilder icons

Vector icons for the command tabs, outliner and panels of the ArchBuilder application.

- Origin: drawn for this project, from scratch, as original work. No icon library, third-party set
  or other product's artwork was copied, traced or used as a model.
- License: the repository license (Apache License 2.0, see `LICENSE` at the repository root).
- Format: one SVG per icon, 24 x 24 view box, single color (`#000`, recolored by theme tokens when
  drawn), 1.5 stroke with round caps and joins, 1.0 for secondary detail, about 2 px padding.
  Plain `path`, `rect`, `circle` and `polygon` elements only. The file name is the icon name that
  `arc_ui::icons::IconAtlas` is given.
- Each file stays under the 16 KiB limit of the atlas.
- Group icons (`group-create`, `group-place`, `group-edit`, `group-separate`): drawn for this
  project from scratch in the same style; no third-party artwork was used.
